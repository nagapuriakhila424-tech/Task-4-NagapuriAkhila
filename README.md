# Data Visualization Project

## 🎯 Objectives
- Analyze business performance through visualizations.
- Identify revenue and order trends.
- Explore product and customer insights.
- Visualize payment method preferences.
- Generate actionable business insights.

## 📌 Description
This repository contains a Data Visualization project developed using Python, Pandas, Matplotlib, and Seaborn. The project analyzes business data through charts and graphs to uncover trends, patterns, and actionable insights for data-driven decision-making.


## 📌 Project Overview
This project focuses on visualizing business data to identify trends, patterns, and insights. Using Python visualization libraries, various charts and graphs were created to analyze revenue, orders, products, payment methods, and customer behavior.


## 🛠️ Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook


## 📂 Dataset
The dataset contains business transaction records including:
- Orders
- Products
- Revenue
- Payment Methods
- Customer Information
- Order Status


## 🔄 Project Workflow
1. Import Libraries
2. Load Dataset
3. Data Cleaning
4. Generate Summary Statistics
5. Revenue Analysis
6. Monthly Order Trend Analysis
7. Product Performance Analysis
8. Payment Method Analysis
9. Correlation Analysis
10. Generate Business Insights


## 📊 Visualizations Created
- Monthly Revenue Trend
- Monthly Order Trend
- Top Products by Revenue
- Payment Method Distribution
- Order Status Analysis
- Referral Source Performance
- Quantity vs Revenue Scatter Plot
- Correlation Heatmap


## 💡 Key Insights
- Revenue trends were identified across different months.
- Top-performing products contributed significantly to overall revenue.
- Customer purchasing patterns were observed through order analysis.
- Certain payment methods were preferred more frequently.
- Correlation analysis revealed relationships between important business variables.


## ▶️ How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run all cells sequentially.
5. Explore the visualizations and insights generated from the dataset.
